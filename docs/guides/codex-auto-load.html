Codex 自动加载路径清单

基于 contrib/codex 源码核实（commit 6219b7c40f）。

$CODEX_HOME 默认为 ~/.codex；$HOME 指真实家目录，二者不同。

一、自动加载​

1. 指令文件 AGENTS.md​

位置作用域说明
$CODEX_HOME/AGENTS.override.md全局优先
$CODEX_HOME/AGENTS.md全局上者不存在时使用
<project_root>/…/<cwd> 每一级目录项目逐级向下全部收集
  • 实现：codex-rs/codex-home/src/instructions/mod.rs:26、codex-rs/core/src/agents_md.rs:155
  • 项目根由 project_root_markers 判定；找不到根时只读 cwd 本身
  • 全局与项目内容以 --- project-doc --- 分隔拼接
  • project_doc_max_bytes（默认 32768）是每个文件的截断上限，不是总量上限；层级深且文件大时累计注入量会显著超出该值

注意：没有 ~/.agents/AGENTS.md 这个位置。

候选文件名与优先级​

每级目录内按以下顺序取第一个命中（codex-rs/core/src/agents_md.rs:234）：

  1. AGENTS.override.md
  2. AGENTS.md
  3. project_doc_fallback_filenames 配置的文件名，按配置顺序

project_doc_fallback_filenames 默认为空数组（codex-rs/config/src/config_toml.rs:78、config.schema.json:5621）。

fallback 在每一级目录都生效，与 AGENTS.md 走完全相同的逐级发现流程——它不是「根目录专属兜底」，而是候选名列表的一部分。

关键点：优先级按目录独立判定，不跨级。

repo/AGENTS.md          ← 命中（该级 AGENTS.md 优先）
repo/CLAUDE.md          ← 忽略（同级已被 AGENTS.md 抢占）
repo/api/CLAUDE.md      ← 命中（该级没有 AGENTS.md）
repo/api/v2/AGENTS.md   ← 命中

cwd 为 repo/api/v2 时加载三份，按 root→cwd 顺序拼接。

⚠️ 某目录同时留有新旧两份文档时，fallback 文件会静默失效，易误判为「改了没生效」。

2. Skills​

位置作用域说明
$HOME/.agents/skills/用户推荐的用户级位置
$CODEX_HOME/skills/用户旧路径，向后兼容
$CODEX_HOME/skills/.system/系统内置技能缓存
<project_root>/…/<cwd> 每一级的 .agents/skills/仓库逐级探测
项目配置层 .codex/skills/仓库
/etc/codex/skills/（Unix）管理员系统配置层
  • 实现：codex-rs/core-skills/src/loader.rs:292（配置层）、:383（.agents/skills 逐级探测）
  • 结构 <root>/<name>/SKILL.md，递归发现，每个根上限 2000 个目录
  • 渐进式加载：仅名称与描述进上下文，正文按需读取

3. 子代理角色​

位置说明
$CODEX_HOME/agents/用户级
<repo>/.codex/agents/仓库级
  • 实现：codex-rs/core/src/config/agent_roles.rs:77
  • 是 .codex/agents/，不是 .agents/agents/——最常写错的一处

4. 配置​

位置说明
$CODEX_HOME/config.toml用户级
祖先目录逐级 .codex/config.toml未信任目录会加载但禁用
<repo_root>/.codex/config.toml同上
/etc/codex/config.toml系统级
  • 实现：codex-rs/config/src/loader/mod.rs:105

二、CLAUDE.md 兼容​

默认不加载。开启方式（~/.codex/config.toml）：

project_doc_fallback_filenames = ["CLAUDE.md"]
  • 语义是 fallback 而非叠加，行为见上节「候选文件名与优先级」
  • 仅对项目级生效。全局 ~/.codex/AGENTS.md 走 instructions/mod.rs:26，硬编码只认 AGENTS.override.md 与 AGENTS.md，不读该配置

另有一次性迁移功能（codex-rs/external-agent-migration/src/source/cla.rs:21），扫描 <repo>/CLAUDE.md、<repo>/.claude/CLAUDE.md、~/.claude/CLAUDE.md，改写正文自称后写成 AGENTS.md。属转换工具，非运行时加载。

选型：长期双栈维护用 fallback 配置；彻底转换用迁移。

三、不支持的引用语法​

AGENTS.md 内容被原样读入、原样拼接，无任何展开环节：

  • 全局：read_to_string（instructions/mod.rs:26）
  • 项目：fs.read_file → 直接 push_str（agents_md.rs:114、:340）

因此 @path、import、include 均无效，写进去就是字面文本。codex 不具备 Claude Code 那种文件引用语法。

（TUI 的 mention_codec.rs 确有 @ 机制，但那是输入框的工具/插件提及编解码，不作用于 AGENTS.md 文件内容。）

复用 ~/.agents/AGENTS.md 的办法​

符号链接，read_to_string 会被 OS 透明跟随：

mv ~/.codex/AGENTS.md ~/.codex/AGENTS.md.bak   # 若已存在
ln -s ~/.agents/AGENTS.md ~/.codex/AGENTS.md

不推荐设 CODEX_HOME=~/.agents——会把 config.toml、agents/、history.jsonl 整套迁走，副作用远大于符号链接。

四、不自动加载​

位置实际含义
~/.agents/plugins/marketplace.json个人插件市场（codex-curated）清单，安装远程插件时由 codex 写入
<repo>/.agents/plugins/marketplace.json仓库自带的插件市场清单
<repo>/.agents/plugins/api_marketplace.json同上，API 类插件
  • 实现：codex-rs/core-plugins/src/marketplace.rs:20、codex-rs/core-plugins/src/remote/share/checkout.rs:24
  • 与 .claude-plugin/marketplace.json、.cursor-plugin/marketplace.json 并列处理
  • 文件存在不会自动启用插件，须显式添加市场 / 安装

五、权限​

.agents/ 在项目根下默认被追加为只读子路径，与 .git 同级待遇；Windows sandbox 另有独立 ACL 保护。

  • 实现：codex-rs/protocol/src/permissions.rs:609、codex-rs/windows-sandbox-rs/src/workspace_acl.rs:20

六、速查​

~/.agents/skills/                  ✅ 自动
~/.agents/plugins/marketplace.json ❌ 需显式安装
~/.agents/AGENTS.md                ❌ 不存在此加载点
~/.codex/AGENTS.override.md        ✅ 自动（全局指令，优先）
~/.codex/AGENTS.md                 ✅ 自动（全局指令）
~/.codex/CLAUDE.md                 ❌ 全局层不支持 fallback
~/.codex/agents/                   ✅ 自动（子代理）
~/.codex/skills/                   ✅ 自动（旧路径）

<repo>/AGENTS.md                   ✅ 自动，root→cwd 逐级
<repo>/CLAUDE.md                   ⚙️ 需配 project_doc_fallback_filenames
<repo>/.agents/skills/             ✅ 自动，root→cwd 逐级
<repo>/.agents/plugins/*.json      ❌ 需显式安装
<repo>/.codex/agents/              ✅ 自动
<repo>/.codex/skills/              ✅ 自动
<repo>/.codex/config.toml          ✅ 自动（未信任则禁用）
