GoDaddy 域名转出新手完全手册

1. 转移前必做（防宕机与防失败）​

  • 检查时间限制：确保域名距离新注册、上次转移或更改所有者已超过 60 天，否则无法转出。
  • 提前迁移 DNS（极其重要）：
    • 原因：域名一旦转出，GoDaddy 会立刻删除该域名的 DNS 记录，导致网站和邮箱瞬间瘫痪。
    • 操作：在新服务商（或第三方 DNS）添加该域名 -> 照抄 GoDaddy 里的所有解析记录（A、CNAME、MX等） -> 在 GoDaddy 将 Name Servers (NS) 修改为新服务商的 NS 地址 -> 等待 24 小时生效后再进行后续步骤。
  • 提前实名认证：如果转入国内厂商（如阿里云、腾讯云），请务必提前一天在厂商后台创建“信息模板”并完成实名认证。

2. GoDaddy 端操作（解锁与获取密码）​

  1. 登录并进入域名设置：在 GoDaddy 控制台点击 My Products (我的产品) -> Domains (域名) -> 找到要转出的域名进入设置。
  2. 关闭隐私保护：将 Domain Protection (域名保护) 降级或关闭，并关闭 Privacy (隐私保护)。
  3. 关闭域名锁：将 Domain Lock (域名锁定) 的开关设置为 Off。
  4. 获取转移密码：点击页面下方的 Transfer domain away from GoDaddy (将域名转出 GoDaddy)。按提示操作后，系统会显示或发送一串包含大小写字母和符号的 Auth/EPP Code (转移密码/授权码)，复制并保存。

3. 新服务商端操作（提交与付费）​

  1. 发起转入：登录新服务商的“域名转入”页面。
  2. 输入密码：按提示输入域名和刚才复制的转移密码。
  3. 选择模板与付费：选择已实名认证的信息模板（国内厂商必需），支付转入费用（通常等同于续费 1 年的费用）。

4. GoDaddy 端操作（核心：加速转移）​

注意：在新厂商付费后，不要傻等 5-7 天，立刻回 GoDaddy 手动放行。

  1. 等待请求送达：在新厂商付费后，等待 15 - 30 分钟。
  2. 进入转移列表：在 GoDaddy 域名控制台，点击左侧导航栏的 Transfers (转移)。
  3. 找到转出项：点击 Transfers Out (转出) 选项卡，然后点击 In Progress (进行中)。
  4. 手动批准：勾选正在转出的域名，点击出现的 Approve Transfer (批准/接受转移) 按钮，确认放行。

5. 转移后检查（善后加固）​

  1. 确认转入：等待 10 分钟左右，前往新服务商后台，确认域名状态已变为“正常/已转入”。
  2. 开启安全锁：在新服务商处开启 转移锁 (Transfer Lock) 和 更新锁 (Update Lock)。
  3. 开启隐私：在新服务商处开启 WHOIS 隐私保护，防止信息泄露。
  4. 测试业务：访问网站并测试企业邮箱，确认一切运转正常。转移彻底结束。
